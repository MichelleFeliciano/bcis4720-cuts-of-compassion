# Cuts of Compassion: Business Plan and System Design (BCIS 4720 Group Project)

Group project for BCIS 4720 at the University of North Texas. Cuts of Compassion is a made-up non-profit that sends volunteer stylists and barbers with mobile styling stations to give free haircuts to people experiencing homelessness, low-income families, and shelters.

This repository holds the **business plan and system design documents** for the project, plus the account pages from the class website. The full website code is not included.

Team (as listed on the business plan cover): Lisa Forte, Brendon Dutton, Maryam Khan, Ayaan Pirani, Michelle Hughes.

## Documents

- `business plan final draft.pdf`: value proposition, revenue model (grants, donations, events), market and competition, SWOT, strategy, organization and management team.
- `design documentation.pdf`: refined entity-relationship design (volunteers, services, donations, donors, events, mobile units, partnerships, clients, appointments), data flow diagrams, and wireframes for the web forms.
- `erd.pdf`: the entity-relationship diagram.
- `webline.pdf`: page layouts for the home, login, about, contact, volunteer sign-up, service request and donation pages.
- `stylesheet.pdf`: the site CSS (dark theme), saved as a PDF.

## Code

- `Final_Group_Project_Code.txt`: ASP.NET (C#) code for the account pages only: account-created confirmation, update account and delete account, using SQL Server data sources. These pages expect the class database and the rest of the site, so they will not run on their own.
