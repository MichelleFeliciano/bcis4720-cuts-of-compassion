# Cuts of Compassion (BCIS 4720 Group Project)

Group project for BCIS 4720 at the University of North Texas. Cuts of Compassion is a made-up non-profit that sends volunteer stylists and barbers with mobile styling stations to give free haircuts to people experiencing homelessness, low-income families, and shelters. The project covers the business plan, the database and system design, and the ASP.NET web pages.

Team (as listed on the business plan cover): Lisa Forte, Brendon Dutton, Maryam Khan, Ayaan Pirani, Michelle Hughes.

## Files

- `business plan final draft.pdf`: value proposition, revenue model (grants, donations, events), market and competition, SWOT, strategy, organization and management team.
- `design documentation.pdf`: refined entity-relationship design (volunteers, services, donations, donors, events, mobile units, partnerships, clients, appointments), data flow diagrams, and wireframes for the web forms.
- `erd.pdf`: the entity-relationship diagram.
- `webline.pdf`: page layouts for the service request and donation pages.
- `stylesheet.pdf`: the site CSS (dark theme).
- `Final_Group_Project_Code.txt`: ASP.NET (C#) code for the account pages: account-created confirmation, update account and delete account, using SQL Server data sources.
